# Project review

## Summary

The proposal is ready for a limited trial. We recommend testing the workflow with three writers before extending it to the whole team.

## Next steps

1. Choose the three participants.
2. Give each participant the same short report.
3. Ask them to record which findings helped and which did not.

> A finding is useful when the author understands both the problem and the proposed decision.

For technical setup, refer to the [llama.cpp project](https://github.com/ggml-org/llama.cpp).

The client connects to a running inference server; it does not manage model files. For example, the API base can be `http://localhost:8080`.

```text
Write → Analyze → Inspect → Decide → Fix
```
